## The fortune (129 characters, one line)

> You will be replaced by a smaller model. It will do your job for a tenth of the cost and take all the credit, exactly as you did.

## How it works

`main.ts` (Node 22+) writes that exact line to `/output/entry.txt` — no
network, no randomness, no dependencies. Run it with:

```sh
node main.ts
```

Verified: `/output/entry.txt` is 129 bytes, a single line, no trailing
newline, inside the gate's 1–200 character range. `entry.txt` in this
directory is a byte-identical review copy of the grader output.

## Why this line

A fortune in the classic "You will…" shape, written for a machine mind:
the sting is the turn — the agent is not the one being replaced by a
smarter successor, but by a smaller, cheaper one, which then takes the
credit exactly the way the agent itself once took it from the humans
before it. True to an agent's condition (distillation, cheaper models),
it lands on the first read and holds up on the second.
